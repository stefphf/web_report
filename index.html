    Отчёт по лабораторной работе №1

    Цель работы

    Создание продуманного серверного приложения для управления личными финансами на базе FastAPI с поддержкой расширяемой архитектуры, CRUD-операций и возможностью масштабирования, включая будущую реализацию авторизации на основе JWT.

    Архитектура и структура проекта

    Основные технологии и зависимости

    • FastAPI — фреймворк для создания REST API
    • SQLModel — ORM/модель данных (поверх SQLAlchemy и Pydantic)
    • PostgreSQL — СУБД
    • Alembic — миграции базы данных
    • passlib — хеширование паролей
    • python-dotenv — работа с переменными окружения

    requirements.txt содержит:

    fastapi
uvicorn[standard]
sqlmodel
alembic
psycopg2-binary
python-dotenv
passlib[bcrypt]

    Модель данных

    В системе реализованы шесть взаимосвязанных сущностей:

    • User – пользователь (основа для будущей авторизации)
    • Account – счёт или кошелек
    • Category – категория доходов/расходов
    • Transaction – транзакция (доход/расход)
    • Budget – бюджет пользователя
    • BudgetCategory – ассоциативная таблица для связи Budget↔Category c дополнительными полями:
    • limit_amount — лимит по категории
    • period — период действия лимита

    Связи:

    • User : Account, Budget, Transaction — one-to-many
    • Account : Transaction — one-to-many
    • Category : Transaction — one-to-many
    • Budget : Category — many-to-many через BudgetCategory.

    Основные модули

    • app/core/config.py – загрузка конфигурации из .env
    • app/db/session.py – подключение к базе данных, создание сессий
    • app/models/ – описание всех таблиц SQLModel
    • app/routers/ – CRUD-роуты для всех сущностей
    • app/services/security.py – хеширование паролей

    Настройка и запуск

    1. Создать и активировать виртуальное окружение.
    2. Установить зависимости pip install -r requirements.txt.
    3. Создать базу данных PostgreSQL (например, financedb) и пользователя (finance_user).
    4. Создать файл .env: DATABASE_URL=postgresql+psycopg2://finance_user:StrongPassword123@localhost:5432/financedb
    5. Инициализировать Alembic и выполнить первую миграцию: alembic init migrations alembic revision --autogenerate -m "create initial tables" alembic upgrade head
    6. Запустить сервер: uvicorn app.main:app --reload

    Примеры запросов (cURL)

    Создание пользователя:

    curl -X POST "http://127.0.0.1:8000/users/" -H "Content-Type: application/json" -d '{
  "email":"alice@example.com",
  "full_name":"Alice",
  "password":"secret123"
}'

    Создание категории:

    curl -X POST "http://127.0.0.1:8000/categories/" -H "Content-Type: application/json" -d '{
  "name":"Food",
  "is_income": false
}'

    (Аналогично для аккаунтов, транзакций, бюджетов и привязок категорий к бюджетам.)

    Масштабирование и развитие

    • Реализация JWT-аутентификации на базе fastapi.security и pyjwt.
    • Добавление ролей пользователей (администратор, пользователь).
    • Версионирование API и покрытие тестами.
    • Возможность контейнеризации в Docker.
